# 2048 经典版 · 设计规格

## 概述
单文件 HTML 网页版 2048 游戏，经典原版风格，键盘 + 触屏双支持。

## 技术栈
- 纯 HTML/CSS/JS，单文件 `index.html`
- 零依赖，浏览器直接打开即玩
- 高分存储使用 localStorage

## 游戏逻辑
- 4×4 网格
- 初始随机 2 个方块（90% 概率出 2，10% 概率出 4）
- 键盘方向键移动，触屏支持滑动手势
- 相同数字碰撞合并，得分累加
- 每次有效移动后随机生成新方块
- 达到 2048 弹窗提示胜利，可选择继续
- 无有效移动时弹窗提示失败
- 新游戏按钮重置

## 视觉风格
- 经典原版配色方案（每个数字独立背景色）
- 方块移动/合并有 CSS transition 动画
- 新建方块有 scale 弹出动画
- 移动端自适应（viewport + flexbox 居中）
